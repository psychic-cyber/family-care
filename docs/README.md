# 🩺 Family Care

> **Care for your loved ones from anywhere.**

Family Care is a modern cross-platform healthcare application that helps caregivers remotely manage medicines, reminders and health information for parents, grandparents and loved ones.

The application is designed with a **premium medical user experience**, **offline-first architecture**, and **voice-enabled medicine reminders** to ensure that elderly family members never miss their medications.

One of the core features of Family Care.

Instead of only showing notifications, the application speaks to elderly users.

Example:

> Assalam-o-Alaikum Baba,
>
> Medicine lene ka waqt ho gaya hai.
>
> Please take your blood pressure medicine.

# 🚀 Installation

Clone Repository

```bash
git clone https://github.com/psychic-cyber/family-care.git
```

Move into project

```bash
cd family_care/mobile
```

Install dependencies

```bash
npm install
```

Android

```bash
npx react-native run-android
```

iOS

```bash
npx react-native run-ios
```
