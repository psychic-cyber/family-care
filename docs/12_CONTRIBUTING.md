---

# Commit Messages

Use conventional commits.

Examples

feat(auth): implement login

feat(patient): add patient module

fix(theme): resolve dark mode issue

docs(prd): update documentation

refactor(reminder): simplify scheduler

style(ui): improve dashboard spacing

test(auth): add login tests

---

# Pull Request Checklist

Before submitting

✓ Code builds successfully.

✓ TypeScript has zero errors.

✓ Android tested.

✓ iPhone tested.

✓ Documentation updated.

✓ No duplicated code.

✓ Theme rules followed.

✓ Reusable components used.

✓ No hardcoded colors.

✓ No hardcoded spacing.

✓ No console errors.
